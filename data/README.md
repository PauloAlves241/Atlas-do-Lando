# Dados do Atlas

- `provincias.json`: base normalizada consumida pelo JavaScript.
- `metadata.json`: dimensões do mapa, origem de Sefante, escala e metadados nacionais.
- `provincias-fonte.csv`: arquivo tabular original usado para gerar o atlas.

As províncias ultramarinas estão presentes na base, embora não apareçam no mapa continental de 2023.
